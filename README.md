# Развертывание, защита и мониторинг сервера на Rocky Linux 9

Учебный инфраструктурный проект по развертыванию, базовой защите (Server Hardening), автоматизации мониторинга и аварийному восстановлению доступа в RHEL-подобной операционной системе.

## Стек и инструменты
* **ОС сервера:** Rocky Linux 9 (VirtualBox, сеть NAT с пробросом портов)
* **Хост-система:** Linux (CachyOS)
* **Безопасность:** OpenSSH (ключи Ed25519), `firewalld`, `dnf-automatic`, SELinux
* **Автоматизация:** Bash, `cron`, `systemd`

---

## Выполненные этапы

### 1. Сетевое взаимодействие и защита SSH (Server Hardening)
* Настроен проброс портов (Port Forwarding: `127.0.0.1:2222 -> 10.0.2.15:22`) для управления сервером по SSH из хост-системы.
* Создан непривилегированный пользователь `sysadmin` с правами `sudo` (группа `wheel`).
* Настроена аутентификация по криптографическим ключам **Ed25519** (`ssh-keygen`, `ssh-copy-id`).
* В конфигурации SSH (`/etc/ssh/sshd_config.d/10-hardening.conf`) запрещены вход под учетной записью `root` (`PermitRootLogin no`) и вход по паролю (`PasswordAuthentication no`).

### 2. Настройка межсетевого экрана и автообновлений
* Проверены и настроены правила `firewalld`: разрешен только необходимый трафик (`ssh`, `dhcpv6-client`), лишние сервисы отключены.
* Установлен и настроен пакет `dnf-automatic` (`apply_updates = yes`) с активацией таймера `dnf-automatic.timer` для автоматического применения обновлений безопасности.

### 3. Скрипт мониторинга и планировщик задач
* Разработан Bash-скрипт [`healthcheck.sh`](./healthcheck.sh), собирающий метрики сервера (Uptime, Load Average, RAM, свободное место на корневом разделе, статус служб `sshd` и `firewalld`).
* Настроен регулярный запуск скрипта каждый час через `cron` (`0 * * * * /usr/local/bin/healthcheck.sh`).

**Пример работы скрипта (`/var/log/server_health.log`):**

### 4. Кейс аварийного восстановления доступа (Troubleshooting)
В рамках лабораторной работы отработан сценарий восстановления доступа при утере пароля администратора:
* Прерывание загрузки в меню **GRUB** и вход в аварийную оболочку `dracut` через параметр ядра `rd.break`.
* Поиск блочных устройств в `/dev/mapper/` и ручное монтирование корневого LVM-тома (`rlm_rocky--server-root`) в `/sysroot`.
* Смена пароля в окружении `chroot` (`passwd`) и инициирование перемаркировки контекстов безопасности **SELinux** (`touch /.autorelabel`).
* Проверка штатной перезагрузки и восстановления доступа по SSH.
